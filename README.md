# Task Axis 

**Task Axis** is a full-stack task management platform where users can create, edit, delete, and bid on tasks. It is built with modern web technologies to provide a smooth, interactive, and responsive experience.

[![Frontend](https://img.shields.io/badge/Frontend-React-blue)](https://reactjs.org/)
[![Backend](https://img.shields.io/badge/Backend-Node.js-green)](https://nodejs.org/)

---

## 🌐 Live Demo

Check out the live project here: [Task Axis Live](https://task-axis.netlify.app/)

---

## 🛠 Features

- **Task Management**: Upload, edit, delete tasks easily.
- **Bidding System**: Place and manage bids on tasks.
- **Authentication**: Secure login/signup via Firebase.
- **Responsive Design**: Mobile-first layout using Tailwind CSS & DaisyUI.
- **Interactive UI**: Carousels & sliders using Swiper.js.
- **Real-time Updates**: Instant reflection of task changes.

---

## 🏗 Tech Stack

**Frontend**
- React.js
- Tailwind CSS
- DaisyUI
- React Router
- Swiper.js

**Backend**
- Node.js
- Express.js
- MongoDB (Database)
- Firebase (Authentication & Hosting)

**Deployment**
- Vercel
- Netlify
